# Canales de comunicación de una empresa

No todos los canales cumplen la misma función. Uno puede servir para visibilidad, otro para confianza y otro para conversión.

## Algunos canales habituales

- Sitio web
- Redes sociales
- Email
- Comunicación interna
- Presentaciones institucionales

## El punto clave

Elegir canales no debería depender de la moda, sino del rol que cada uno cumple dentro del sistema de comunicación.
